# Screen design references

The screen concepts below were supplied with the product brief and informed the navigation, visual language, and core review journeys in the IDSync portfolio prototype, including the profile and document-vault view.

> **Reference-artifact notice:** These images are exploratory mockups, not screenshots of the implemented demo. They contain example record details and statements about privacy, encryption, processing, integrations, accuracy, and correction timelines that have not been verified. Do not present those statements as implemented or validated product capabilities. The interactive demo uses fictional content and does not process identity documents.

## Design language

The included `sovereign_calm/DESIGN.md` files describe a pale blue surface palette, dark high-contrast text, blue interaction accents, and compact typographic hierarchy. The implemented demo uses this direction with locally available system fonts, responsive layouts, clear status labels, and explicit demo/limitations messaging.
